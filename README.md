🌦️ WeatherMap
Asynchronous Client-Side Weather Map Application (SPA)
📦 Repository:https://github.com/MashailGasim-mo/Weather-Map.git

📖 Overview
Weather Map is a web-based application that allows users to explore weather information for different locations. The project provides a simple and user-friendly interface for accessing weather data and viewing location-based weather information.

🛠️ Technologies & APIs Used

HTML5
CSS3
JavaScript
Weather API


## Main Features

- Search for cities by name.
- Display current temperature and weather conditions.
- Show humidity, wind speed, atmospheric pressure, visibility, cloud cover, and sunrise.
- Display a five-day forecast based on the available forecast data.
- Explore locations on an interactive map.
- Switch between Arabic and English.
- Switch between light and dark themes.
- Switch between Celsius and Fahrenheit.
- Save recent searches and favorite cities.
- Use the device location with the user's permission.
- Responsive layout for desktop, tablet, and mobile.
- Loading indicators and error messages.
- Save preferences and locations in the browser.

🔄How to Run
Download or clone this repository.
2. Open `script.js`.
3. Replace `your aoi key ` with a valid API key.
4. Save the file.
5. Open the project folder in Visual Studio Code.
6. Run `index.html` using the Live Server extension.
7. Search for a city and explore its weather information.

A working internet connection is required to load weather data, map tiles, fonts, and external libraries.
